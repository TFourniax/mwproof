# Failure tests / pivot criteria

ProofMW should be killed or materially pivoted if any of these fail.

1. **Prediction test** — on historical projects, calibrated ProofMW distributions do not outperform a simple base-rate / spreadsheet baseline.
2. **Decision test** — lenders/insurers say the analysis is interesting but it does not change diligence time, pricing, structure, covenanting or go/no-go decisions.
3. **Data test** — we cannot obtain enough planned-vs-actual outcomes to calibrate materially better than public generic assumptions.
4. **Neutrality test** — customers prefer incumbent broker/engineering opinions and see no value in an independent layer.
5. **Integration test** — ingestion requires so much bespoke consulting that gross margin structurally resembles consulting rather than software/data.
6. **Liability test** — contractual/regulatory liability forces the company to carry risk before the model is sufficiently calibrated.

## Pivot candidates if ProofMW fails

- Sell the public/private infrastructure event graph and time-to-power intelligence directly to developers and capital providers.
- Narrow to European grid/permitting schedule-risk intelligence.
- Narrow to independent compute-collateral verification only if market pull is materially stronger.
