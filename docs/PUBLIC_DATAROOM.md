# Public-data-room surrogate: Start Campus SINES / SIN02

A true lender data room is normally confidential, and no legitimate public lender data room for a live European hyperscale project was found during the V1 research pass.

Instead, ProofMW ships a public-information surrogate assembled from independent public source classes:

- Start Campus developer disclosures for campus capacity, SIN02 size and public target timing.
- Open Compute Project facility/certification material.
- Portuguese environmental-authority records referencing Data Center Sines 4.0 / RECAPE.

This is more useful for V1 engineering than inventing a fake confidential data room because it forces the product to distinguish evidence from assumptions.

The missing private documents are themselves part of the model: interconnection agreement, EPC schedule, equipment purchase orders, detailed permits, carrier contracts, insurance, tenant/offtake and financing documents. The V1 marks assumptions for these gaps as synthetic and refuses a verified grade.
